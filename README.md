# 知识大陆 · 闯关学习

把教学大纲与学习资料变成闯关游戏：地图闯关 → 看讲解 → 答题 → 判定 → EXP/星星/成就，
外加错题本、知识图谱（知识点依赖）与学习档案。

## 怎么用

打开本站即可开始。手机上用浏览器打开后选「**添加到主屏幕**」，
就能变成全屏 App，并且**装好后断网也能玩**。
